# H&M Customer Churn Prediction

: 구매 이력만으로 이탈 고객을 얼마나 예측할 수 있는지, 그 한계는 어디인지 확인한 프로젝트

## 1. 프로젝트 요약
- **문제**: H&M 거래 데이터에는 이탈 라벨이 없다. 이탈 기준부터 직접 정의하고, 이탈할 고객을 예측한다.
- **접근**: 고객별 최대 재구매 간격의 75분위수(203일)를 이탈 기준으로 삼아 cut-off 날짜(2020-03-03)를 정했다. cut-off 이후 203일간 구매가 없으면 이탈(1)이다. 피처는 cut-off 이전 데이터만으로 만들어 미래 정보가 섞이지 않게 했다.
- **결과**: 고객 1,143,652명 기준, LightGBM ROC-AUC **0.848** (학습 3초), CatBoost 0.8486 (학습 52초).
- **핵심 발견**: 피처를 3단계(RFM / 트렌드 / 시퀀스)로 늘리고 하이퍼파라미터 튜닝(RandomizedSearchCV, Optuna)까지 했지만 AUC는 0.848~0.849에서 움직이지 않았다. 병목은 모델이 아니라 **구매 이력만 있고 행동 로그가 없다는 데이터의 정보량**이라고 판단했다.

## 2. 데이터와 이탈 라벨 정의
- 데이터 출처: [H&M Personalized Fashion data (Kaggle)](https://www.kaggle.com/datasets/sohyunjun0401/h-and-m-personalized-fashion-data)
- 분석 대상: cut-off 이전 가입 고객 중 30일 이상 활동한 고객 1,143,652명
- 라벨 정의
  - cut-off 날짜 = 데이터 종료일 − 203일 = 2020-03-03
  - 203일은 고객별 최대 재구매 간격의 75분위수 (고객의 75%는 이 기간 안에 다시 구매했다)
  - 이탈(1): cut-off 이후 203일간 구매 기록 없음 / 유지(0): 최소 1회 이상 구매
  - 이탈률 50.0%로 클래스가 균형이라 정확도도 의미가 있지만, 주 지표는 ROC-AUC로 했다
- 누수 방지
  - 피처는 cut-off 이전 531일의 데이터만 사용
  - 초기 작업에서 recency를 포함하면 정확도가 0.98, 제외하면 0.81로 크게 갈리는 누수 의심 사례를 확인하고 라벨/피처 생성을 다시 설계했다 (`archives/temp.ipynb`에 비교 결과가 남아 있다)

## 3. 피처 엔지니어링 (3단계)
| 버전 | 추가한 피처 | 개수 | 의도 |
|---|---|---|---|
| v1 | RFM / 활동성(최근 90/180일) / 구매 간격 / 다양성 / 고객 메타 | 16 | 기본 구매 행동 |
| v2 | 구매 감소율, 지출 변화율, 다양성 감소율, 구매 리듬 가속도 등 | +6 (22) | 이탈 직전의 "변화"를 포착 |
| v3 | 최근 5회 구매 간격(`interval_t1`~`interval_t5`) | +5 (26) | LSTM/RNN 없이 시퀀스 정보가 도움이 되는지 확인 |

- `last_interval`은 `interval_t1`과 상관관계 1.0이라 제거했다.
- `interval_t1~t5`의 결측은 채우지 않고 트리 모델에 맡겼다 (구매 횟수가 적다는 정보 자체가 신호일 수 있음).
- 범주형은 원-핫 인코딩(`drop_first=False`), 학습/검증은 80:20 층화 분할(914,921 / 228,731)로 모든 노트북에서 같은 분할을 쓴다.

## 4. 모델링 결과
### 4-1. 베이스라인 모델 비교 (v3 피처, 검증 세트)
| 모델 | ROC-AUC | Accuracy | F1 | 학습 시간 |
|---|---|---|---|---|
| CatBoost | **0.8486** | 0.7687 | 0.7728 | 51.8s |
| XGBoost | 0.8482 | 0.7690 | 0.7728 | 4.6s |
| LightGBM | 0.8480 | 0.7692 | 0.7725 | 3.0s |
| RandomForest | 0.8368 | 0.7602 | 0.7599 | 39.2s |

### 4-2. 단계별 실험: 무엇을 해도 오르지 않았다
| 실험 단계 | 시도 내용 | 최고 AUC | 변화 |
|---|---|---|---|
| v1 베이스라인 | RFM 16개 피처 | 0.8485 | - |
| v2 피처 추가 | 트렌드 피처 +6개 | 0.8486 | +0.0001 |
| v2 튜닝 | RandomizedSearchCV | 0.8482 | −0.0004 |
| v3 피처 추가 | 시퀀스 피처 +5개 | 0.8486 | +0.0000 |
| v3 튜닝 | Optuna (30 trials, 30% 샘플) | 0.8463 | −0.0023 |

- 트렌드/시퀀스 피처는 기존 RFM과 겹치는 정보라 추가 이득이 없었다.
- Optuna가 기본 파라미터보다 낮게 나온 것도 튜닝 방법의 문제라기보다 데이터 정보량이 한계라는 쪽을 가리킨다. 다만 튜닝은 30% 샘플과 적은 trial 수로 했으므로 "튜닝으로는 더 오르지 않았다" 정도로 읽는 것이 정확하다.
- 최종 선택은 **LightGBM**. CatBoost와 AUC 차이가 0.0006으로 잡음 수준인데 학습은 약 17배 빠르다.

### 4-3. 이탈 신호
| 순위 | 피처 | 해석 |
|---|---|---|
| 1 | `recency` | 오래 안 산 고객일수록 이탈 가능성이 높다 |
| 2 | `unique_product_groups` | 구매 카테고리가 다양하지 않을수록 이탈 위험이 높다 |

## 5. 한계와 개선 방향
```
있는 것 : 구매 횟수, 금액, 간격, 카테고리
없는 것 : 클릭 로그, 세션 시간, 앱 접속 기록, 장바구니 이탈
```
이탈은 "마지막 구매 이후 아무것도 하지 않았다"는 결과인데, 그 원인을 설명할 행동 데이터가 없어서 모델이 배울 수 있는 패턴에 한계가 생긴다.

| 우선순위 | 방법 | 기대 효과 |
|---|---|---|
| 1 | 클릭/세션 행동 로그 추가 | 가장 큰 개선 여지 (현재 데이터로는 검증 불가) |
| 2 | LightGBM + XGBoost 앙상블 | AUC 0.001~0.003 수준의 소폭 개선 예상 |
| 3 | LSTM/Transformer 시퀀스 모델 | 불확실, 작업량 많음 |

- 검증 세트는 고객 단위 무작위 분할이다. 피처는 cut-off 이전, 라벨은 이후 기간이라 시간 누수는 없지만, 다른 기간(다른 cut-off)에서도 같은 성능이 나오는지는 확인하지 못했다.

## 6. 활용 방안 (제안)
예측 확률 구간별로 다른 액션을 주는 방식을 생각해 볼 수 있다. 아래 구간은 예시이고, 쿠폰 비용 대비 효과로 검증한 값은 아니다.

| 이탈 확률 구간 | 세그먼트 | 액션 예시 |
|---|---|---|
| 0.8 이상 | 이탈 임박 | 고가 쿠폰 + 개인화 추천 |
| 0.6 ~ 0.8 | 이탈 위험 | 신상품 추천 이메일 + 등급 혜택 안내 |
| 0.3 ~ 0.6 | 관심 필요 | 재구매 시점에 맞춘 자동 알림 |
| 0.3 미만 | 안전 | 액션 없음 |
